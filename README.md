拾光时钟  v1.0
时间与日期，一眼看清。
════════════════════════════════════════

【启动】
双击「拾光时钟.exe」即可运行。
免安装、无需联网；建议右键 exe → 发送到 → 桌面快捷方式，
以后从桌面直接打开。

【功能】
· 大号数字时间，时、分、秒一眼看清
· 模拟表盘，时针 / 分针 / 秒针实时走动
· 完整日期、星期、农历日期
· 本地时区（UTC+08:00）、今日已过进度
· 深色 / 浅色双主题，切换带渐变动画
· 窗口置顶、最大化 / 还原、全屏显示
· 一键复制当前日期和时间
· 自动记住主题、置顶、12/24 小时制和窗口位置

【快捷键】
F11             全屏显示
Esc             退出全屏
T               切换深色 / 浅色主题
H               切换 12 / 24 小时制
P               窗口置顶开关
Ctrl + C        复制当前日期和时间
F1              快捷键说明
双击顶部标题栏  最大化 / 还原
右键窗口        打开快捷菜单（含 12/24 小时制等）

【鼠标操作】
· 拖动顶部空白区域：移动窗口
· 拖动窗口边缘：调整大小
· 右上角按钮：主题 / 置顶 / 最小化 / 最大化 / 关闭
· 双击顶部空白区域：最大化 / 还原

【数据与隐私】
本程序完全离线运行，不联网、不收集任何数据。
设置保存在：
    %APPDATA%\ShiguangClock\settings.ini
删除该文件夹即可恢复默认设置。
卸载：直接删除本程序文件夹和上面的设置文件夹即可。

【系统要求】
Windows 10 / 11。
使用系统自带的 .NET Framework 4.8，无需另外安装运行库。
时间读取自 Windows 系统时钟；如时间不准，请在
“设置 → 时间和语言 → 日期和时间”中开启自动同步。

【常见问题】
1. 首次运行提示“Windows 已保护你的电脑”
   这是对本地自制、未购买数字签名的程序的常规提示。
   点“更多信息”→“仍要运行”即可。程序不联网，也不修改系统。

2. 双击没有反应
   请先解压，不要把 exe 留在压缩包预览窗口中运行；
   并确认系统为 Windows 10 或 Windows 11。

3. 界面看起来偏大或偏小
   程序已适配系统缩放。若使用多显示器且缩放比例不同，
   可以把窗口拖到主显示器后重新启动。

4. 想恢复默认外观
   关闭程序，删除 %APPDATA%\ShiguangClock 文件夹，再启动。
